# Roohana

A responsive fashion storefront built with React and JavaScript. Roohana features a curated clothing collection, warm editorial styling, and product prices displayed in Indian rupees.

[![Roohana storefront home page](./screenshots/roohana-home.png)](./screenshots/roohana-home.png)

## Features

- Responsive storefront layout for desktop and mobile
- Product collection with category filters and search
- Shopping bag with quantity controls, subtotal, and a ₹5,000 free-shipping threshold
- Login and account-creation forms
- Newsletter signup interaction

## Built with

- React
- JavaScript
- Vite
- CSS

## Run locally

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

Create a production build with:

```bash
npm run build
```

## Notes

The login, account-creation, newsletter, and checkout interactions are frontend demonstrations; they are not connected to a backend or payment provider. Product imagery and fonts are loaded from external services.
